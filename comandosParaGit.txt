COMANDOS DO GIT PARA NAVEGAR E CRIAR BRANCHS (PRATOS DE PIZZA):

(PARA CRIAR UMA BRANCH)
git checkout -b feature/nome-da-tarefa


(PARA VER AS BRANCHS QUE EXISTEM)
git branch -a


(PARA MUDAR PARA UMA BRANCH - SUA TAREFA)
git checkout nome-da-branch


(ENVIAR AS ALTERAÇÕES PARA O GIT - DEPOIS DE PRONTO - !!!!!APENAS DA PRIMEIRA VEZ!!!!!) - (NA SEGUNDA VEZ EM DIANTE USA: git push origin feature/nome-da-tarefa)
git push -u origin feature/nome-da-tarefa


(ENVIAR AS ALTERAÇÕES PARA O GIT APÓS A PRIMEIRA VEZ)
git pull origin develop


=--=-=-=-=-

*** O QUE FAZER SEMPRE QUE ABRIR SEU PROJETO? ***
você precisa sempre atualizar o que tem na branch develop!! Entao você vai:
- abrir o terminal
- ir no "v" na direita do "+"
- clicar em gitBash

- digitar: git pull origin develop
(isso vai puxar todas informações recentes do nosso projeto!! Depois disso é só mudar para a sua branch - "git checkout feature/sua-branch")
